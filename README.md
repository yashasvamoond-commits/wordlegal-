**हिन्दी विधिक मसौदा स्टूडियो** — न्यायालय में जमा करने योग्य **लीगल साइज़ (8.5 × 14 इंच)** दस्तावेज़ बनाने,

## ✨ विशेषताएँ

### 1. लीगल साइज़ पर सच्चा पृष्ठ-लेआउट
- पृष्ठ आकार: **लीगल 8.5 × 14″, लीगल 13, A4, लेटर** — खड़ा/भूमि दोनों
- हाशिया: मानक न्यायालयीन (बायाँ 1.25″), फाइलिंग (बायाँ 2″) आदि प्रीसेट
- **वास्तविक पृष्ठ-विभाजन इंजन** — पाठ पृष्ठ पर सटीक बँटता है, पंक्ति बीच से नहीं कटती
- शीर्षक/पाद लेख, पृष्ठ संख्या (पृष्ठ 1 / N), पंक्ति क्रमांक, सीमा-रेखा, वॉटरमार्क
- पृष्ठ विच्छेद (Page Break) एवं संपादक में पृष्ठ गाइड

### 2. पूर्ण वर्ड-प्रोसेसर (रिबन UI)
होम · सम्मिलित करें · लेआउट · समीक्षा · विधिक · दृश्य

- फ़ॉन्ट परिवार (नोटो सेरिफ़/संस देवनागरी, मंगल, निर्मला, टाइम्स, एरियल, कूरियर), आकार, रंग
- मोटा/तिरछा/रेखांकित/काटें, अधोलेख/उर्ध्वलेख, हाइलाइट
- संरेखण (बाएँ/मध्य/दाएँ/समायोजित), बिंदु व क्रमांकित सूची, इंडेंट, पंक्ति अंतर
- **विधिक ब्लॉक शैलियाँ**: न्यायालय शीर्षक, प्रकरण संख्या, पक्षकार (बनाम), विषय पंक्ति,
  प्रार्थना शीर्षक, हस्ताक्षर खंड, सत्यापन, टिप्पणी, उद्धरण
- तालिका, चित्र, लिंक, क्षैतिज रेखा, खोजें-बदलें, अनडू/रीडू, शब्द-अक्षर गणना
- **{{फ़ील्ड}} टोकन** — केस विवरण बदलते ही पृष्ठ पर स्वतः भर जाते हैं

### 3. विधिक शब्दकोश (ऑफ़लाइन)
- **439 प्रविष्टियाँ**, 12 श्रेणियाँ — न्यायालय, आपराधिक, दीवानी, प्रक्रिया, साक्ष्य,
  दस्तावेज़, पारिवारिक, राजस्व, मुहावरे, **लैटिन सूत्र**
- प्रत्येक शब्द: हिन्दी, English, अर्थ, **न्यायालयीन प्रयोग-वाक्य**, प्रचलन (सामान्य/विशिष्ट/दुर्लभ)
- हिन्दी + अंग्रेज़ी दोनों से खोज, श्रेणी/प्रचलन फ़िल्टर, पसंदीदा, हाल में देखे गए
- एक टैप में शब्द या प्रयोग-वाक्य मसौदे में जोड़ें

### 4. 30 तैयार न्यायालयीन प्रारूप
ज़मानत एवं हिरासत · परिवाद एवं शिकायत · विचारण · साक्ष्य · अपील एवं पुनरीक्षण ·
परिवार · दस्तावेज़ — प्रत्येक के साथ **कब प्रयोग करें**, **चेकलिस्ट** एवं पूरा मसौदा
(धारा 480, 482, 483, 187(3), 262, 250, 223, 346, 228, 94, 348, 351, 85, 430, 438, 415,
144 BNSS 2023 आदि)। साथ में **44 न्यायालयीन वाक्यांश** (एक टैप में जोड़ें)।

### 5. विधिक भाषा-शोधन
अनौपचारिक शब्दों के लिए विधिक पारिभाषिक सुझाव — “वकील → अधिवक्ता”, “कोर्ट → न्यायालय”,
“केस → प्रकरण”, “गवाह → साक्षी”, “सजा → दंड”, “तहत → अंतर्गत”, “लेकिन → परंतु”, “जरूरी → ज़रूरी”;
अंग्रेज़ी शब्दों के हिन्दी पर्याय; टंकण/विराम-चिह्न दोष; शब्दकोश-आधारित निकट वर्तनी जाँच।
प्रत्येक सुझाव एक टैप में लागू।

### 6. धारा मैपिंग — पुरानी → नई संहिता
**IPC → BNS**, **CrPC → BNSS**, **साक्ष्य अधिनियम → BSA** (01.07.2024 से प्रभावी) —
खोज, अंग्रेज़ी विवरण, महत्वपूर्ण टिप्पणियाँ (अग्रिम ज़मानत, मजिस्ट्रेट की दंड-शक्ति,
इलेक्ट्रॉनिक साक्ष्य, डिफ़ॉल्ट ज़मानत आदि)।

### 7. निर्यात एवं साझा
- **PDF** — पिक्सेल-सटीक वही पृष्ठ, ठीक 8.5 × 14 इंच (612 × 1008 pt) MediaBox
- **DOCX** — MS Word में खुलने योग्य; `w:pgSz 12240 × 20160` (लीगल) एवं हाशिया सहित
- **HTML** (प्रिंट-तैयार) एवं **TXT**
- APK में फ़ाइल बनने पर Android शेयर शीट (WhatsApp, ईमेल, Drive, “फ़ाइल में सहेजें”)

### 8. अन्य
- टैबलेट/फ़ोन — **खड़ा व भूमि** दोनों, ऑटो-फ़िट ज़ूम, बिना क्षैतिज स्क्रॉल
- स्वतः सहेजना, संस्करण इतिहास (स्नैपशॉट/बहाली), दस्तावेज़ प्रतिलिपि, पसंदीदा
- **पूर्णतः ऑफ़लाइन**, डेटा डिवाइस पर ही (localStorage) — कोई सर्वर नहीं
- **द्विभाषी UI — अंग्रेज़ी (प्राथमिक) एवं हिन्दी**; मसौदे, प्रारूप व शब्दकोश हिन्दी में ही रहते हैं (शीर्ष पट्टी के `EN/हि` बटन या सेटिंग्स से बदलें)
- गहरा/हल्का थीम, विधिक चिह्न पट्टी (। ॥ ₹ § — ०-९)
- Android बैक बटन, स्टेटस-बार, कीबोर्ड `adjustResize` समर्थन

## 🛠️ स्वयं बनाएँ

```bash
npm ci
npm run dev            # ब्राउज़र में विकास (http://localhost:5173)
npm run build          # उत्पादन बिल्ड → dist/
npx cap sync android   # वेब → Android
cd android && ./gradlew assembleDebug     # app-debug.apk
cd android && ./gradlew assembleRelease   # app-release.apk
```

रिलीज़ हस्ताक्षर (वैकल्पिक): `WL_KEYSTORE`, `WL_STORE_PASS`, `WL_KEY_ALIAS`, `WL_KEY_PASS`
एनवायरनमेंट सेट करें; अन्यथा debug कुंजी से हस्ताक्षरित होगा।

**स्वचालित बिल्ड:** `main` पर पुश करते ही GitHub Actions
(1) APK बनाकर release asset के रूप में प्रकाशित करता है और
(2) Playwright से टैबलेट/फ़ोन/भूमि पर UI, शब्दकोश, प्रारूप, PDF/DOCX निर्यात जाँचता है
(परिणाम `ci-run/` में — report.json एवं स्क्रीनशॉट)।
